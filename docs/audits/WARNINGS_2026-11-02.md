### Resolution strategy per category

**`-Wunused-parameter` — 15 sites** — Omit the parameter name at the definition, or mark `[[maybe_unused]]`. For interface-conformance stubs the signature must stay; only the name goes.

**`-Wunused-variable` — 4 sites** — Delete the declaration, or use it. If it was meant to be consumed, this is a latent bug rather than dead code — inspect before deleting.

**`-Wreorder` — 3 sites** — Reorder the member DECLARATIONS to match the constructor initialiser list. Extremely local, no behavioural change.

**`-Wtype-limits` — 2 sites** — An `unsigned >= 0` test is always true, so the guard is dead and the branch it protects is unconditional. Fix the condition; do not silence it.

**`-Wcomment` — 1 site** — A line comment ends with a backslash and is joined to the next line. Rephrase so it does not end in `\`.

**`(none)` — 1 site** — Macro redefinition in a test file (`ALLOW`). Rename, or `#undef` first.

**`-Wunused-but-set-variable` — 1 site** — A value computed then discarded. Decide whether it is dead code or an unimplemented check before removing it.

## Clearance plan

All **27** source locations are resolvable. The order is deliberate: the sites
that indicate real defects are fixed first, and the largest category is last
because it is the only one needing a policy decision rather than an edit.

### Batch 1 — real defects (fix, do not silence) — 3 sites

| Site | Warning | Why it is a defect |
|---|---|---|
| `src/engine/post_session_analyzer.cpp:158` | `>= 0` on unsigned | `report.execution_success` is unconditionally true, so post-session archival can never report failure |
| `tests/unit_and_integration_tests.cpp:2107` | `>= 0` on unsigned | Dead guard in the test intended to catch the above |
| `src/roadmap/db_client.cpp:2841` | `is_new_visitor` set but unused | A computed "is this a new visitor" result discarded inside `record_analytics_event` — the function whose write path aborts the visitor suite |

**Effort:** small. **Risk:** behaviour changes — that is the point.
**Verification:** the post-session analyzer must be able to return
`execution_success == false`, proven by a test. `is_new_visitor` must be
investigated before deletion.

### Batch 2 — mechanical, no behaviour change — 9 sites

| Site group | Sites | Fix |
|---|---:|---|
| `-Wreorder` — `native_ws_transport.hpp` | 3 | Three report lines for one logical fix: reorder member declarations to match the initialiser list |
| `-Wunused-variable` | 4 | Delete, or use |
| `-Wcomment` | 1 | Rephrase the comment so it does not end in `\` |
| `"ALLOW" redefined` (`tests/auth_tests.cpp`) | 1 | `#undef` before redefining, or rename |

**Effort:** small. **Risk:** low — but a `-Wunused-variable` that was meant to be
consumed is a hidden bug; read each before deleting.

### Batch 3 — policy decision — 15 sites

| Site group | Sites | Options |
|---|---:|---|
| `-Wunused-parameter` | 15 | (a) omit parameter names at the definition; (b) `[[maybe_unused]]`; (c) per-file suppression for interface stubs |

15 is concentrated: **5 of the 15 are `gate0_bootstrap.hpp`**, whose parameters
exist only to satisfy an interface the code must never implement (`:37`). The
signature must stay; only the names go.

### Batch 4 — structural: why 220 was ever printed — 1 build change

`CMakeLists.txt:41` compiles the same sources into 17 targets, measured at
**8.15× amplification**. Clearing 27 sites without addressing this leaves the CI
log at roughly the same volume. Either:

- build the shared sources once as an `OBJECT` library and link it into each
  target, or
- keep the duplication and report **de-duplicated location counts** in CI.

**Effort:** medium. **Risk:** an `OBJECT` library changes the build graph; land
it separately, verified by a clean build and a green CTest run.

## Verification of clearance

A clearance is only proven by repeating the same measurement:

```bash
rm -rf /tmp/build-audit
cmake -S . -B /tmp/build-audit -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/build-audit -j"$(nproc)" 2>&1 | tee /tmp/verify_build.log

# count UNIQUE SOURCE LOCATIONS, not emitted lines:
#   dedupe on (file, line, message) so the 8x multi-target re-emission collapses
grep -oE '[^ ]+\.(cpp|hpp|h):[0-9]+.*warning:.*' /tmp/verify_build.log \
  | sort -u | wc -l
# target: 0
```

and `ctest --test-dir build --output-on-failure` must still report **16/16**.
A warning that vanishes while a test breaks has been silenced, not resolved.
